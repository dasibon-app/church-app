# 사용한 외부 소프트웨어

`church-app.html`은 아래 소프트웨어를 사용합니다. 각 소프트웨어는 자체 라이선스를 따르며, 이 저장소의 [사용 허락](LICENSE)은 이 소프트웨어들에는 적용되지 않습니다.

| 이름 | 용도 | 라이선스 | 포함 방식 |
|---|---|---|---|
| Noto Sans KR (Regular, Bold) | PDF 인쇄용 한글 글꼴 | SIL Open Font License 1.1 | 앱 파일 안에 포함 |
| Noto Sans KR | 화면 글꼴 | SIL Open Font License 1.1 | Google Fonts에서 불러옴 |
| SheetJS Community Edition 0.18.5 (xlsx) | 엑셀 읽기·쓰기 | Apache License 2.0 | cdnjs에서 불러옴 |
| jsPDF 2.5.1 | PDF 만들기 | MIT | cdnjs에서 불러옴 |
| jsPDF-AutoTable 3.8.2 | PDF 표 | MIT | cdnjs에서 불러옴 |
| html2canvas 1.4.1 | 화면을 이미지로 | MIT | cdnjs에서 불러옴 |

# 교회 교적·재정 — 설치와 업데이트 (구독자 배포판 v1.0.4)

만든 사람: 다시본교회 주진규 목사 · [홈페이지](https://dasibon.icg21.com/) · [웹주보](https://dasibon-church.jinkyuju.workers.dev/) · [유튜브](https://www.youtube.com/@dasibon)

> 이 설치 방법은 시험 중입니다. Claude의 기능과 화면은 바뀔 수 있습니다. 첫 테스터의 결과에 따라 이 문서를 고칩니다.

## 준비
- Claude **Pro 이상** 구독 (무료 계정은 자료 저장 불가)
- Claude 설정에서 파일 만들기·수정 기능 켜기
- church-app.html 파일 (약 1.8MB)

## 설치
1. Claude에서 새 대화를 열고 church-app.html을 첨부합니다.
2. 아래 글을 붙여넣고 보냅니다.

```
첨부한 church-app.html 파일을 한 글자도 바꾸지 말고, 내 계정의 아티팩트로 그대로 게시해 줘. 제목은 '교회 교적·재정'.
이 앱이 쓰는 기능은 데이터베이스(db), 사용자 확인(user), 파일 저장(downloads), 구글 연결(mcp)이야.
mcp는 아래 도구만 허용해 줘.
- Google Drive: create_file, search_files
- Google Sheets: get_spreadsheet, update_spreadsheet, batch_clear_values, get_values, update_values
게시한 뒤에는 나만 볼 수 있게 비공개로 두고, 링크는 나에게만 알려 줘.
```

3. 앱이 열리면 설정 → 교회 정보를 입력하고 저장 → 새로고침해도 남는지 확인합니다.
4. 화면에 '클라우드 동기화됨'이 보여야 합니다. '이 기기에만 임시 저장 중'이면 입력하지 마세요.

## 업데이트
1. 전체 백업(JSON)을 받습니다.
2. 새 church-app.html을 첨부하고 아래 글을 보냅니다.

```
첨부한 새 church-app.html로, 내가 이전에 게시한 '교회 교적·재정' 아티팩트를 같은 주소에 업데이트해 줘.
- 새 파일을 한 글자도 바꾸지 말고 그대로 올려 줘.
- 새로 만들지 말고 기존 아티팩트를 갱신해 줘. 데이터베이스의 자료는 건드리지 마.
- 허용한 권한(db, user, downloads, mcp)은 그대로 유지해 줘.
```

3. 설정 → 앱 정보에서 버전을 확인합니다.

## 꼭 지킬 것
- 링크를 '누구나 볼 수 있게' 공유하지 마세요. 저장된 성도 정보가 보일 수 있습니다. 함께 쓸 사람은 이메일로 한 사람씩 초대하세요.
- 앱을 지우면 자료도 지워질 수 있으니 먼저 백업하세요.

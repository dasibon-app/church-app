# 예산안 사용법 (1.4.0)

다음 회계연도 예산을 미리 짜 보고, 심의 자료로 출력하는 기능입니다. **보고서·통계 → 예산안** 탭에서 씁니다. 만드는 중인 안은 실제 예산에 영향을 주지 않습니다.

## 1. 안 만들기
- ‘＋ A안 만들기’를 누르고 시작점을 고릅니다.
  - **올해 예산 그대로 복사**: 설정의 올해 예산을 그대로 가져옵니다.
  - **올해 실적(연말 예상)에서 시작**: 지금까지의 실적으로 시작합니다(만원 단위 반올림).
  - **다른 안 복제**: B안을 만들 때 A안을 복사해 조금만 바꿀 수 있습니다.
  - **빈 안으로 시작**
- 최대 두 개(A안·B안)까지 만들 수 있습니다.

## 2. 금액 고치기
- 수입은 헌금 종류별, 지출은 항목·세부 항목별로 입력합니다. 세부 항목에 금액을 넣으면 항목 금액은 세부 항목의 합으로 계산됩니다.
- 올해 예산·올해 실적 옆에 증감액과 증감률이 바로 보입니다. 올해 예산이 0원인 항목은 ‘신규’로 표시됩니다.
- **일괄 증감(%)**, **수입 가정(%)**, **올해 실적으로 채우기**, **올해 예산 복사**를 쓸 수 있고, ‘↶ 직전 상태로’로 되돌립니다.
- 항목마다 **비고(심의 설명)** 를 적을 수 있습니다.

## 3. 비교하고 출력하기
- **A·B 비교**에서 두 안의 차이를 한눈에 봅니다.
- **심의용 PDF**: 예산안 요약 · 수입 예산안 · 지출 예산안 · 안 비교 · 심의 결과 기록란이 나옵니다. 큰 글씨, 가로·세로를 고를 수 있습니다.
- **엑셀 받기**도 같은 내용입니다.

## 4. 확정하기
- **이 안으로 확정**을 누르면 설정 → 연간 예산의 해당 연도 예산이 그 안으로 바뀝니다.
- 확정 직전에 복구 지점이 자동으로 만들어집니다. 잘못 확정했다면 설정 → 데이터에서 되돌립니다.
- 실적과 다른 연도의 예산은 바뀌지 않습니다.
